# Sources : politique

Revue ciblée du 4 novembre 2026. L'univers contient 400 questions et quatre difficultés : Afrique 80, Amérique du Nord 60, Amérique du Sud 60, Asie 80, Europe 80, Océanie 40. Chaque continent répartit ses questions également entre les quatre niveaux. Le mode général réunit ces six ensembles ; l'Amérique centrale est incluse ici dans l'Amérique du Nord.

Les références de lecture ont été réaffectées par pays ou institution au lieu d'une seule source pour tout un bloc de difficulté. Les liens privilégient les constitutions, les parlements et les organisations concernées. Les questions civiques générales peuvent conserver une référence régionale. Une page générale reste une lecture complémentaire et ne garantit pas que tous les éléments d'une question y soient explicitement démontrés.

Repères principaux :

- [Union africaine : Acte constitutif](https://au.int/en/constitutive-act).
- [États-Unis : Constitution, publication du Congrès](https://constitution.congress.gov/constitution/).
- [Argentine : Constitution, publication du Congrès](https://www.congreso.gob.ar/constitucionNacional.php).
- [Japon : Constitution, Chambre des représentants](https://www.shugiin.go.jp/internet/itdb_english.nsf/html/statics/english/constitution_e.htm).
- [Allemagne : Loi fondamentale](https://www.gesetze-im-internet.de/englisch_gg/englisch_gg.html).
- [Australie : Constitution, Parlement fédéral](https://www.aph.gov.au/About_Parliament/House_of_Representatives/Powers_practice_and_procedure/Constitution).
- [Conseil de l'UE : règles de vote](https://www.consilium.europa.eu/en/council-eu/how-does-the-council-vote/).

Les énoncés visent des repères institutionnels et historiques, sans recommandation partisane. La revue a porté sur la distribution, les formulations repérées, les seuils constitutionnels sélectionnés et l'affectation des références. Elle ne remplace pas un audit juridique exhaustif ni une surveillance continue des réformes constitutionnelles.
