# Notes éditoriales — sciences, mathématiques et programmation

112 questions originales : 48 mathématiques, 48 sciences, 16 programmation ; 28 par difficulté et 11 vrai/faux. Les réponses mathématiques ont été recalculées lors de la rédaction. Les explications sont des synthèses originales, sans citation textuelle.

Les pages suivantes ont été réellement consultées par recherche web le 31 octobre 2026 pour vérifier les faits spécialisés. Les questions correspondantes portent une propriété `source` avec leur URL. Les autres questions reposent sur des connaissances scolaires stables ; elles ne prétendent pas avoir été individuellement documentées par une source externe.
